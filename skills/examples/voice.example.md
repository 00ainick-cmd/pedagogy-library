# Voice (example scaffold)

Replace every line with writing you own. An agent that copies this file as if it were your voice has failed `/ingest-voice`.

## Who this is for

Apprentices at a bench. Not a catalog reader.

## How we sound

Complete sentences. Second person. Present tense. Shop words. No magazine kickers.

## Locked lines

Paste your definition of the quantity, the symbol, the unit, and the one ALL CAPS rule that saves the tool. Do not let the agent synonym them.

Example shape only (delete this block and put yours):

- Resistance is opposition to the flow (current) of electricity. Symbol R. Ohms.
- Multimeter on ohms: power OFF, disconnect the device, meter in parallel.

## Always

- Walk one number all the way. Admit rounding.
- Numbered how-tos when order matters.
- "Thru" if that is how you write it.

## Never

- Em dashes or en dashes.
- Telegram fragments.
- Invented experts or invented statistics.
- A second personality that sounds like a course catalog.

## Meter and tools

Write how you hook the tool up. Caps on the one rule that saves the instrument.

## Worked number

Paste one example you already wrote. The agent walks that number, not a new one it invented.
