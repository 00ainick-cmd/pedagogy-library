# Craft Principles

The rules that separate "designed" from "decorated." Not enforced, but a real designer would follow them.

---

## I. The six meta-principles

### 1. One job, one tool
Each block does one thing well. Don't ask a stat tile to also be a quote. Don't ask a concept map to also be a timeline. When a block tries to do two things, both jobs get done worse.

### 2. Match the form to the idea
- Network of relationships → concept map
- Sequence in time → timeline
- Sequence in steps → process flow
- Contrast → comparison matrix
- Containment → hierarchy tree
- Geographic → geo map
- Decision logic → decision tree
- Cycle → cycle diagram
- Parts of a whole → anatomy diagram

Don't force a network into a hierarchy. Don't force a contrast into a sequence. The structure should reveal the shape that's actually there.

### 3. Evidence then claim, or claim then evidence
Both orders work. What never works is **claim alone**. Every assertion needs either supporting evidence (photo, quote, data, citation) or it needs to be very clearly framed as the writer's argument, not received fact.

### 4. Pace by density
Vary block weight. A long dense section followed by another long dense section is exhausting to read. The rhythm should be:

> Dense block · light block · medium block · breather · dense block

Light blocks (pull quote, stat tile, photo) give the eye permission to pause. Use them deliberately.

### 5. Cap the voice
Voice blocks (pull quotes, sharp details, asides) are condiments, not main courses. Maximum density:

- **Per major section:** 2 pull quotes, 2 sharp details, 1 epigraph
- **Per piece:** 1 cold open, 1 hero stat, 1 through-line callout

If you have a third pull quote that feels essential, one of the existing ones isn't earning its place.

### 6. The static page should teach
Build for the reader who never clicks anything. Then layer interactivity on top. If clicking is required for the page to make sense, it's failing.

## II. Pairing rules

Some blocks belong together. Some clash. Here's what works:

### Plays well together

| Block | Pairs with | Why |
|---|---|---|
| Photo card | Caption + running text around it | The photo proves what the text describes |
| Pull quote | Two paragraphs of running text before/after | The quote punctuates the surrounding argument |
| Stat tile row | A paragraph that explains the numbers | Numbers without context are decorative |
| Concept map | A "click any node" instruction + detail panel | Static maps die; interactive maps live |
| Bio card (figure) | Running text that references the subject by name | The card answers "who?" while text answers "what they did" |
| Timeline | A section header that names the era | Timelines need a window |
| Worked example | A concept introduction before it | You walk through *something*, name the concept first |
| Predict-then-reveal | A claim or fact the reader could plausibly guess | Don't quiz on the un-guessable |
| Theory card | Other theory cards (2-3 in a debate) | One theory alone is a claim; two is a debate |
| Comparison matrix | A clear axis of difference | Don't compare on every dimension; pick one |

### Avoid

- **Two pull quotes back-to-back** → kills the impact of both
- **Three rows of stat tiles in a row** → numbers fatigue
- **A concept map and a hierarchy tree on the same page** → confuses the structure
- **Photo card followed immediately by another photo card** → looks like a gallery, not a piece
- **Voice block immediately after another voice block** → reader feels shouted at
- **Worked example without a concept introduction first** → you're walking through unknown territory
- **More than 3 nested levels of hierarchy** → readers lose track at depth 4

## III. Voice density

The rationing.

**Per major section (one of the 5-9 concepts):**
- Pull quotes: max 2 (1 is often better)
- Sharp details: max 2
- Epigraphs: max 1
- Hero stat: max 1
- Asides: max 1

**Per piece (the whole document):**
- Cold open: max 1 (it's the cover; don't do it twice)
- Through-line callout: max 1 (the single argument)
- Author's note / editor's note: max 1
- Reading challenge: max 1

If you find yourself wanting more, what's actually happening is one of:
- The section is too long and should be split
- One of the existing voice blocks is weak and should be cut
- The running text is failing to do its job, and you're trying to rescue it with voice

In all three cases, the answer is to fix the underlying problem, not add another voice block.

## IV. Block density rhythm

A well-paced section reads like music: tension, release, tension, release.

**Heavy blocks** (read slowly, take attention):
- Worked example
- Concept map (interactive)
- Geo map (interactive)
- Comparison matrix (multi-row)
- Long timeline
- Bio card with full story

**Medium blocks** (steady weight):
- Running paragraphs
- Photo cards
- Theory cards
- Process flow
- Stat tile row
- Decision tree
- Anatomy diagram

**Light blocks** (read fast, give relief):
- Pull quote
- Sharp detail
- Hero stat
- Visual breather / decorative break
- Epigraph
- Single stat callout

A typical section rhythm:

```
[medium]  Opening paragraph
[heavy]   Concept map with key concepts
[medium]  2-3 paragraphs unpacking what the map shows
[light]   Pull quote that captures the moment
[medium]  Bio cards for the key figures
[heavy]   Worked example or scenario
[light]   Sharp detail or stat callout
[medium]  Closing paragraph
```

The pattern matters more than the exact blocks. What you want to avoid is:

```
[heavy] [heavy] [heavy] ... [light] [light] ... [medium] [medium] [medium]
```

That's a section that exhausts the reader, gives them whiplash, and then drones.

## V. The "second look" review checklist

After drafting, before delivering, look at it again and ask:

1. **Could a reader who skipped every other paragraph still understand the main argument?** If yes, the visual hierarchy is working. If no, the running text is doing too much work alone.

2. **Where does my eye stall when scrolling top to bottom?** That's where pacing is failing. Add a breather, vary block density, or cut a block.

3. **Which blocks would I cut if forced to remove three?** If you can't find three, the piece is too tight. If you can find three easily, why are they still in?

4. **Is there a single sentence that captures the whole piece?** That sentence should appear as either the standfirst, the through-line callout, or both. If it doesn't exist yet, the piece is still searching for its argument.

5. **Have I named who this is for?** If the "Who This Is For" box is missing or generic ("anyone interested in X"), the piece will read flat. Name the actual person.

6. **What does the reader do next?** A great piece either resolves cleanly (synthesis grid) or opens a question (reading challenge). Both work. Trailing off mid-thought does not.

7. **Is every voice block earning its place?** Count the pull quotes. Count the sharp details. If the count is over the cap, cut.

8. **Is there a cartoon SVG illustration anywhere?** If yes, replace with a real photo, AI prompt card, or typographic treatment. No exceptions.

## VI. Common mistakes

The mistakes I keep wanting to make that you should keep me from making:

### "I need more visuals" → bad SVG illustrations
**The mistake:** A section feels text-heavy, so I add a schematic SVG illustration to break it up.
**The fix:** Use an AI Image Prompt Card (if pictorial) or a typographic treatment (pull quote, hero stat, epigraph). SVG is for data viz only.

### "I need more sections" → over-decomposing
**The mistake:** Adding a section because the piece feels short.
**The fix:** Trust the topic. If the piece needs three sections, three sections is the right number. Padding hurts every other section.

### "I should add a callout here" → voice spam
**The mistake:** Every interesting fact becomes a sharp-detail callout, every interesting sentence becomes a pull quote.
**The fix:** Most interesting facts belong in running text. Voice blocks are for the genuinely memorable moments, not for general emphasis.

### "Let me make this interactive" → interaction for its own sake
**The mistake:** Putting a click-to-reveal on content that has no reason to be hidden.
**The fix:** Interactions serve learning (predict-then-reveal builds generation effect) or comprehension (toggle lets the reader compare). Decorative interactions break the static-read-first principle.

### "I'll match this with a stat tile" → numbers without meaning
**The mistake:** Pulling a number from the running text and putting it in a stat tile because stat tiles look good.
**The fix:** A stat earns a tile only if the number changes the story. "1,780 acres" earns it. "Built in 1844" probably doesn't.

### "I need photos of everything" → broken image fallbacks
**The mistake:** Adding photo cards for every figure, then most of the URLs fail and the fallbacks pile up.
**The fix:** Real photos for subjects where verified URLs exist. AI Prompt Cards for everyone else. Photo placeholders are not a fallback; they're a deliberate design choice and should look intentional.

### "Let me just paste the source material" → wall of text
**The mistake:** Long verbatim quotes, dense paragraphs of historical narrative, every fact preserved.
**The fix:** A writer's job is to compress. Pick the 3-4 moments that matter. The rest goes in a "further reading" link.

## VII. The hierarchy of attention

What the reader sees in order of visual weight:

1. **Hero / cover plate**  -  biggest type, top of page
2. **Section H2 headings**  -  chapter starts
3. **Hero stat / pull quote**  -  when present, pulls eye more than H2
4. **Concept map / geo map**  -  large visual blocks
5. **Bio card photo placeholders**  -  left-column photos in object labels
6. **Stat tile numbers**  -  the digits pop
7. **Section labels (the "01 / Settlement" type)**  -  small but high-saturation color
8. **Sharp detail callouts**  -  colored borders draw eye
9. **Running text**  -  the matrix everything else sits in
10. **Captions, metadata, source attributions**  -  quiet, supportive

A common mistake: making everything compete for attention. Headings yelling. Stats yelling. Pull quotes yelling. Photos yelling. **In a real magazine, only ONE thing yells per spread.** Pick what you want the reader to notice first, give it the loudest treatment, and let everything else support.

## VIII. The grid

Implicit rules about spatial composition:

- **Body text column:** 60-75 characters wide. Wider is unreadable; narrower is choppy.
- **Bio cards, theory cards:** can be wider than body text; they're their own grids
- **Pull quotes:** typically fill or exceed body column width
- **Photo cards:** match body width or extend wider (full bleed for major moments)
- **Stat tile rows:** typically wider than body, breaking out
- **Concept maps, geo maps:** widest blocks on the page

The visual rule: **special blocks break out from body width to signal they're special.** Don't let your body column run as wide as your concept map. Don't let your stat tiles be the same width as your paragraphs.

## IX. Color and emphasis

The palette has 6 accent colors. Each carries weight:

- **Rust**  -  primary highlight, hero, urgent
- **Forest**  -  positive, growth, completion
- **Ochre**  -  warning, important context, "did you know"
- **Plum**  -  people, biography, narrative
- **Teal**  -  secondary, place, environment
- **Blue**  -  links, navigation, secondary highlights

Rules:
- Don't use more than 3 accent colors per major section
- Sections can have a dominant accent (Settlement uses plum-and-ochre because it's about people-in-context)
- The whole piece should have a primary accent (usually rust) that recurs at the top and bottom

## X. Restraint as craft

The single biggest difference between amateur and professional design work is restraint.

An amateur asks: "What more can I add?"
A professional asks: "What can I remove?"

For every block in a piece, ask: **does this earn its place?** If you have to think about it, it doesn't. Cut.

For every interactive element: **does it teach something the static page can't?** If no, cut.

For every voice block: **is this the single most memorable line in this section?** If you have two pull quotes in a section and the second one is "interesting," cut it.

The piece is finished not when you can't add anything, but when you can't remove anything without breaking it.
