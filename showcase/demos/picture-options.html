Fundamentals of DC

Identifying a Series Circuit

Series circuits have only one path for current to flow. Start at the source, trace through each part in turn, and you come back to the source without reaching a branch, a point where the path splits into two or more paths.

Series circuit

A circuit with only one path for current. The parts are connected end to end, so the same current flows through each one.

Why It Teaches

On the job the technician sees the schematic, not a sentence describing it. Asking the question on the drawing practices the task itself, and the closer practice is to the real task, the more of it carries over to the job.

The picture and its one-line description give two routes to the answer and link the symbol to the idea. The description names what is drawn; the picture carries the decision, so the words never give the answer away.

Each wrong option is a real mistake (a parallel branch, a mixed circuit), and its feedback says what is in that drawing. The course owner singled this question out in review because pictures freshen a check that would otherwise be all text. It became a rule: picture options wherever a picture is the skill.

How It Is Built

The question is the course's shared ask card, .ask in lesson-parts.js, which accepts any markup inside an option. Each option holds a small SVG schematic drawn at 124 by 80 units with thick lines, so it still reads at 390 pixels wide, and a few lines of CSS set the picture beside its letter and its description.

The feedback pops up over the question: Continue when right, Try again when wrong. The whole row is the tap target, at least 88 pixels tall, and each drawing has its own accessible name.
